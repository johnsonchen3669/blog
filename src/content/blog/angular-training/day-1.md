之前有聽說過鐵人賽的活動，但一直沒有參加過，這次剛好趁著轉換工作的機會，想說來挑戰看看 Angular 框架。

Angular 是一個由 Google 所開發的前端框架，從 2016 年開始推出 Angular 2 版本，每半年左右就會有一個版本更新。是非常穩定的框架，語法向後兼容，因此這次在使用新寫法的同時，也盡量提供一些舊語法的對應方式，讓大家在看到舊專案時不會感到困惑。

> Angular JS 是 2010 年推出的版本，與現在的 Angular 差異非常大，通常會稱為 AngularJS 來做區分。

這次所介紹的 Angular 框架，主要的文章內容包含：

- 環境建置
- 基礎語法
- 元件開發
- 路由
- 服務
- API 串接
- 表單處理

 會在學習 Angular 相關基礎後，用上述的概念來製作範例專案。

## 系列文章適合誰

這系列文章適合給有 TypeScript 經驗的朋友來閱讀，因為 Angular 本身是用 TypeScript 開發的，所以對於 TypeScript 有所了解會更有幫助。

若未接觸過 TypeScript 也沒關係，因為 TypeScript 是 JavaScript 的超集，所以你可以把 TypeScript 當作是 JavaScript 的加強版來學習。
